# AGI Finance Academy v1.0

Institutional economics/finance **curriculum library** distilled from *Principles of Economics* (Mankiw).

This is **not** an engine and **not** a chapter summariser.

## Mission

Convert every taught concept into reusable institutional knowledge objects so AGI understands mechanisms — cause, effect, industry impact, valuation, forecast, and decision frameworks — without re-reading the book.

## Architecture

Architecture v1.0.1 is LOCKED. Academy only expands knowledge. Soft consumers expose views for KF, KCV, IIE, VE, FLE, IRP, and FIML without modifying those packages.

## Local book PDFs

Place copyrighted PDFs under `/workspace/books/` (gitignored) or set `AGI_ACADEMY_MANKIW_PDF`. Never commit PDFs.
